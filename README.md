# Hydroponics Monitoring Controller

This KiCad 10 project contains the circuit schematic for an ESP32-S3 hydroponics monitoring controller. The schematic includes the ESP32-S3 control unit and connections for water-quality and environmental sensors.

## My contribution

I co-led hardware work on the team project, contributing to circuit design, PCB schematic capture, and PCB layout. I helped translate monitoring and control requirements into board-level design decisions and coordinated those decisions with the project team.

This repository publishes the schematic and KiCad project settings. A camera-based plant detection system with on-device Edge AI is a planned extension.

## Open in KiCad

Keep both KiCad files in the same folder. Open `hydroponics-monitoring.kicad_pro` in KiCad 10, then select `hydroponics-monitoring.kicad_sch` in the project tree.
